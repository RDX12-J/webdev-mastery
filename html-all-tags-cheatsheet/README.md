# Full-Stack Web Development Learning Portal (All-in-One: Noob se Pro) 🚀

Ek complete, modern, aur interactive web development learning portal jisme web dev sikhne ke liye zaroori **sabhibhi languages, tools, aur sources** bilkul **alag-alag (unmixed) dedicated sections** me diye gaye hain, sabhi **Basic / Noob se lekar Pro / Advanced level** tak.

---

## 🌟 7 Dedicated Tracks (Alag-Alag Sections)

1. 📄 **HTML5 Master Track (122 Tags)**:
   - Starting root elements se lekar modern `<dialog>`, `<details>`, Web Components `<template>`, `<slot>`, aur legacy `<marquee>` tak complete catalog.
2. 🎨 **CSS3 Styling & Layouts Track**:
   - Selectors, Box Model, Units (`px`, `rem`, `vh`), Colors & Gradients.
   - 1D Flexbox visual alignment aur 2D CSS Grid systems.
   - Positioning (`sticky`, `absolute`), Media Queries (Mobile-First).
   - Modern CSS: Variables (`var()`), Keyframe animations, Glassmorphism, `:has()` parent selector, aur Container Queries.
3. ⚡ **JavaScript (JS) Master Track**:
   - Variables (`let`, `const`), Data types, Strict equality `===`, Arrow functions, Template literals.
   - High-Order Array Methods (`map`, `filter`, `reduce`), Object destructuring, Spread operator.
   - DOM manipulation, Event listeners, LocalStorage / SessionStorage.
   - Promises, `async/await`, Fetch API, Closures, aur Event Loop concurrency.
4. 🐙 **Git & GitHub Track**:
   - `git init`, `git status`, `git add`, `git commit -m`, `git log`.
   - Branching (`git switch -c`), Merging, Remote repository setup (`git push`, `git pull`).
   - `.gitignore` rules, Resolving merge conflicts, Pull Requests (PR) workflow, aur `git stash`.
5. ⚛️ **React & Modern Frontend Track**:
   - Vite modern setup, JSX syntax rules, Components & Props.
   - Dynamic interactivity with `useState`, Lifecycle & API calls with `useEffect`.
   - Tailwind CSS utility classes, Global Store with `Zustand`, aur Next.js SSR overview.
6. 🛠️ **Backend & APIs Track**:
   - Client-Server Architecture, HTTP Methods (`GET`, `POST`, `PUT`, `DELETE`), Status Codes (200, 404, 500), JSON format.
   - Node.js & Express.js REST API creation (CRUD), Middleware, CORS.
   - Databases (PostgreSQL SQL vs MongoDB NoSQL), Password Hashing (Bcrypt), JWT Auth, WebSockets.
7. 🗺️ **Full-Stack Roadmap & DevTools**:
   - Month 1 se Month 6 tak ka structured learning path.
   - VS Code shortcuts & extensions.
   - Chrome DevTools inspection guide.
   - 100% Free Cloud Deployment platforms (Vercel, Netlify, Render, Supabase).
